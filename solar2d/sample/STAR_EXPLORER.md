# StarExplorer plugin integration

The complete StarExplorer game and its recovered Win64 Pascal plugin proof are maintained in the **nexus-lab** repository under `StarExplorer`. On this workspace that is `C:\gitdev\nexus-lab\StarExplorer`.

The shared Lua bridge, Solar2D integration and generic sample remain in this package repository. Game source, asset cleanup records, import definitions, rebuild script, runtime screenshot and recovery evidence belong to the StarExplorer project.

From StarExplorer, run `plugin-proof\Build-Proof.ps1 -OutputRoot C:\StarExplorerProof` to rebuild and stage the Win64 proof. Its README records prerequisites and validation scope.
